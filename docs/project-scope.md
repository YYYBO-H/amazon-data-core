# 项目范围

## 产品定义

Amazon Data Core 是可由兼容 Agent 安装和调用的本地 Amazon 经营数据引擎。它把订单、库存、广告和结算数据同步到用户自己的电脑，保留原始数据与处理血缘，并判断数据是否足够完整、及时和一致，可以用于后续分析。

项目交付的是可信数据层、安装工具和只读查询接口，不是某个模型生成的经营结论。

## 目标用户

第一类用户是没有研发团队的 Amazon 小卖家和运营人员。他们可以让具备本机执行能力的 Agent 按仓库契约完成安装，但不需要理解数据库、ETL、MCP 或 Amazon API 的内部实现。

第二类用户是服务商和技术团队。他们可以替换连接器、数据库或分析规则，同时复用统一数据模型、数据血缘和质量检查。

## 用户得到什么

一条完整链路包括：

1. 在用户本机安装并验证 Core；
2. 由用户在本机完成必要的 Amazon 应用授权；
3. 同步订单、FBA 库存、可选广告和闭账结算数据；
4. 展示每个数据集的覆盖范围、同步状态和质量问题；
5. 让兼容 Agent 通过只读 MCP 查询同一份本地事实。

仅克隆仓库或完成 LWA token 交换不代表交付完成。真实连接器同步、质量检查和 MCP 读回结果都必须分别验证。

## 稳定核心

- 跨数据源的统一数据模型；
- 增量同步、分页、限流、重试、幂等与断点续传；
- 原始数据、标准化数据和处理批次的血缘；
- 时区、币种、站点、业务日期、归因期和修正版本；
- 完整性、及时性、对账、顺序和恢复检查；
- 本地存储、稳定 CLI 和只读 MCP 查询面；
- 可验证的安装和诊断流程。

模型提示词、经营建议和广告优化规则可以替换，不属于稳定核心。

## 非目标和安全边界

- 本项目不是通用 Agent、聊天界面或广告优化 Agent；
- 本项目不绑定特定大模型或 Agent 产品；
- 主观经营建议必须与可验证的数据事实分开；
- 缺失或未完成的数据不能被解释为业务值为零；
- 项目不绕过 Amazon 应用注册、OAuth 同意、验证码、角色或 API 审批；
- 所有接口都应明确展示同步失败、延迟、部分覆盖和口径差异；
- MCP 查询保持只读，不代替用户修改 Amazon 店铺或广告账户。

## 兼容性的含义

“兼容 Agent”表示该产品能够读取仓库说明、在用户电脑上执行命令，并配置或调用标准 MCP stdio 服务。只有聊天能力、没有本机工具权限的产品，仍然可以阅读说明或分析用户提供的结果，但不能自动完成安装和本地同步。

项目不把任何单一 Agent 的界面或专有配置格式当作公共协议。公共入口是 CLI、HTTP API、标准 MCP stdio 和仓库内的 Agent 安装契约。
